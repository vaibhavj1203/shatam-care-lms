# Local history

session, kept for reference but not part of the project's documentation.

- `native-install-attempt.md` — a native (non-Docker) bench install that was
  tried and fully reverted. Useful if anyone attempts one again: it records the
  exact toolchain versions Frappe requires (Python 3.14, Node 24) and the
  misleading errors you get with the wrong ones.
